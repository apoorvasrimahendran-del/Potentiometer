# Potentiometer
# Potentiometer Reading Using Arduino 🎛️

# About the Project

This project demonstrates how to interface a potentiometer with an Arduino board and read its analog values.When the potentiometer knob is rotated, its resistance changes, causing the analog input value to change. Arduino reads these values and displays them through the Serial Monitor.

# Components Required

- Arduino Uno
- Potentiometer
- Jumper wires
- USB cable

# Working

The potentiometer is connected to the Arduino's analog pin. As the knob is rotated, the Arduino reads the changing voltage and displays the corresponding values on the Serial Monitor.


# Learning Outcome

Through this project, I learned how to use analog input pins, read changing values and understand how a potentiometer works with Arduino.
